# Piano samples

From the **Salamander Grand Piano V3** by Alexander Holm, a Yamaha C5 grand recorded note by note,
licensed under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
These are the mp3 files published with [Tone.js](https://tonejs.github.io/audio/salamander/): one
sample every minor third from A1 to C7 (C, D♯, F♯ and A of each octave). The app plays the notes in
between by changing the playback speed by up to a semitone and a half.
